# Tax & Audit Tools

[English](README.md) · [Deutsch](README.de.md) · [简体中文](README.zh-CN.md)

我开发用于税务初步筛查、报告准备和财务核对的开源工具，关注如何明确假设，并让复核人员能够从结果追溯到输入依据。

这些项目将专业工作流程与 AI 辅助开发结合，目前均为有明确适用边界的原型。欢迎提供可复现的虚构案例、方法问题和实际使用中的改进意见。

## 帮助完善一个具体步骤

选择一个虚构场景，只改变一个重要输入。说明预期结果、实际结果和不清楚的步骤；法规问题请附适用期间及官方来源。反馈按周整理。

请通过相应项目的 Issues 提交反馈，支持中文、德语和英语。

公开演示和 Issue 只使用虚构数据。本项目入口没有统计脚本或信息提交表单；GitHub Pages 会按其隐私政策记录通常的访问信息。演示运行正常不代表专业判断已经完成，也不提供申报服务。
