# Tax & Audit Tools

[English](README.md) · [Deutsch](README.de.md) · [简体中文](README.zh-CN.md)

Ich entwickle Open-Source-Werkzeuge für steuerliche Vorprüfungen, die Berichtsvorbereitung und die Abstimmung von Finanzdaten. Dabei sollen Annahmen sichtbar bleiben und Ergebnisse bis zu den Eingaben nachvollziehbar sein.

Die Projekte verbinden fachliche Arbeitsabläufe mit KI-gestützter Entwicklung. Es sind Prototypen mit dokumentierten Grenzen. Reproduzierbare Beispiele, fachliche Rückfragen und Hinweise zur Bedienung helfen bei der Weiterentwicklung.

## Einen Ablauf verbessern

Wählen Sie einen fiktiven Fall und ändern Sie eine wesentliche Eingabe. Beschreiben Sie Erwartung, tatsächliches Ergebnis und den unklaren Schritt. Bei Rechtsfragen nennen Sie Zeitraum und amtliche Quelle. Rückmeldungen werden wöchentlich gesichtet.

Rückmeldungen bitte über die Issues des jeweiligen Projekts. Deutsch, Englisch und Chinesisch sind willkommen.

In öffentlichen Demos und Issues ausschließlich fiktive Daten verwenden. Diese Projektseite enthält keine Analysewerkzeuge oder Formulare. GitHub Pages protokolliert übliche Besucherdaten nach der GitHub-Datenschutzerklärung. Eine funktionierende Demo ersetzt keine fachliche Beurteilung oder Einreichung.

Eigener Code und eigene Dokumentation unter MIT; Hinweise zu Drittbestandteilen gelten weiter.
